# Test-only control-plane fixtures
`TestBrowserServer` in `_test.go` substitutes only CatalogProvider, Tailnet and Registry interfaces. It uses real HTTP handlers, SQLite and reverse proxy. Fixture audit exposes controlled test requests and listener addresses; never session cookies or credentials. It does not establish trusted TLS, tailnet DNS or remote approval.

`TestTCPServiceSDK` uses actual tsnet nodes, production `EmbeddedTailnet.Listen` and TCP runtime with local testcontrol/DERP. testcontrol automatically adds HTTPS certificate domains; its explicit no-HTTPS full netmap is asserted through production Status before claiming TCP works without certificates. The dial seam in `TestTCPRuntimeCancelsPendingDial` proves shutdown cancellation only; binary forwarding is separately exercised with real sockets.
